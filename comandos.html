02.1 — referência rápida

Filtre pelo que importa agora.

"Essenciais" cobre o ciclo init → commit → push. "Produtividade" são atalhos que devs experientes usam sem pensar.

essencial

git init

Transforma uma pasta comum em repositório Git. Cria a estrutura interna em .git/.

git init
essencial

git status

Mostra o que mudou desde o último commit e o que está pronto para entrar no próximo.

git status
essencial

git add

Move alterações do working directory para a staging area. Use . para tudo ou um caminho específico.

git add .
essencial

git commit

Grava um snapshot do que está em staging. A mensagem é parte da documentação do projeto.

git commit -m "feat: adiciona login"
essencial

git push

Envia commits locais para o repositório remoto (GitHub, GitLab, etc).

git push origin main
essencial

git pull

Baixa e integra mudanças do remoto na sua branch atual. Sempre antes de começar a trabalhar.

git pull
produtividade

git status -s

Versão compacta do status. Duas colunas: o que está em staging, o que não está.

git status -s
produtividade

git stash

Guarda mudanças não commitadas numa pilha temporária. Útil quando você precisa trocar de branch agora.

git stash
produtividade

git log --oneline

Histórico em uma linha por commit. O log padrão é verboso demais para uso diário.

git log --oneline --graph -10
02.2 — convenção

Boas mensagens de commit não são opcionais.

A convenção tipo: descrição deixa o histórico legível e habilita changelogs automáticos.

conventional commits — exemplos
$ git commit -m "feat: adiciona filtro por categoria" nova funcionalidade visível ao usuário $ git commit -m "fix: corrige cálculo do total no carrinho" correção de bug $ git commit -m "refactor: extrai serviço de autenticação" muda código sem alterar comportamento $ git commit -m "docs: atualiza README com instruções de setup" apenas documentação
